# Glow Beauty Co. - Portfolio Website

An inclusive beauty e-commerce website inspired by Rare Beauty. Features modern design, shade finder, and community focus.

## Features
- Inclusive beauty brand design
- Interactive shade finder (50 shades)
- Add to bag functionality
- Values/mission section
- Community gallery (#GlowCommunity)
- Newsletter signup
- Fully responsive

## Technologies
- HTML5, CSS3, JavaScript
- Pink + Burgundy color palette
- Modern sans-serif typography
- Rounded corners and soft shadows
